**Author:** Pelayo Gonzalez de Lena (@pelamovic)
**Date:** 2026-03-26
**Status:** Design phase

---

## 1. Problem Statement

EpiProfile-PLANTS uses hardcoded `rt_ref` values in each MATLAB module to constrain
chromatographic peak detection to a narrow RT window (typically +/-5 min around the
expected elution time). This dramatically reduces search space and false positives.

The 106 new H2A/H2B/H1 modules generated by `expand_modules_with_ptms.py` all have
`rt_ref = 0`, which causes EpiProfile to scan the **full chromatographic range**
(1--43 min on ZenoTOF / Evosep One 30 SPD). This is:

- **Slow:** ~8x more scans per peptide
- **Error-prone:** higher chance of false-positive peak assignments
- **Inconsistent:** H3/H4 modules have calibrated RTs; H2A/H2B/H1 do not

### Key Principle

RT is 100% chemistry/instrument-dependent, NEVER organism-dependent. The same peptide
sequence with the same modifications on the same column/gradient produces the same RT,
whether the histones come from *Arabidopsis thaliana*, mouse, or human. Delta max
between different chromatographic chemistries = 23.37 min (from RT_COMPARISON.tsv).

## 3. Strategy Comparison

### 3.1 Empirical RT Extraction (RECOMMENDED -- Tier 1)

**Approach:** Extract XICs from existing .ms1 data for each H2A/H2B/H1 peptide
using known m/z values, find peak apex RT.

**Advantages:**
- Uses YOUR actual data on YOUR instrument/gradient
- No model bias or modification handling issues
- Ground truth for the specific chromatographic setup
- Can be run immediately with no extra software

**Disadvantages:**
- Only works for peptides actually present in the data
- Some H2A/H2B/H1 peptides may have low abundance
- Need multiple samples to get robust RT estimates

**Implementation:** `extract_empirical_rt.py` (Script 3)

**Expected accuracy:** +/- 0.5 min (sufficient for EpiProfile's +/-5 min window)

### 3.2 DeepLC Prediction (Tier 2 -- Complementary)

**Approach:** Deep learning model trained on >500K peptides from ProteomeTools
and other large-scale RT datasets. Calibrate with known H3/H4 RTs.

**Tool:** DeepLC (https://github.com/compomics/deeplc)

**Advantages:**
- Can predict RTs for peptides not detected experimentally
- Handles custom modifications via SMILES or atomic composition
- Transfer learning to new instruments/gradients via calibration peptides

**Disadvantages:**
- NOT trained on propionylated histone peptides (critical gap)
- EpiProfile uses non-standard derivatization (propionic anhydride on K, N-term)
- Modification encoding requires careful SMILES definition
- Prediction error ~2-5 min even after calibration (acceptable for +/-5 min window)
- Requires Python environment with TensorFlow

**Key Limitation -- Propionylation:**
DeepLC's default modification dictionary does NOT include propionylation (pr).
Custom modifications must be defined via atomic composition:
- Propionylation: H(4) C(3) O(1) -> +56.026215 Da
- In DeepLC format: `"pr": {"atomic_composition": {"H": 4, "C": 3, "O": 1}}`

**Implementation:** `predict_rt_deeplc.py` (Script 2)

### 3.3 Prosit / MS2PIP (Tier 3 -- Limited Utility for RT)

**Prosit** (https://www.proteomicsdb.org/prosit/):
- Primarily a fragment ion predictor (MS2 spectra)
- Has RT prediction but limited to Orbitrap/HCD training data
- Does NOT handle custom modifications well
- Web API only -- no local calibration possible

**MS2PIP** (https://github.com/compomics/ms2pip):
- Fragment ion prediction (like Prosit, but local)
- No RT prediction capability
- Useful for spectrum library generation, not RT

**Verdict:** Neither Prosit nor MS2PIP are suitable for RT prediction of
propionylated histone peptides on ZenoTOF.

### 3.4 iRT / Relative RT Strategy (Tier 2 -- Multi-Instrument)

**Approach:** Convert absolute RTs to a relative scale using calibration anchors.
Instead of "peptide X elutes at 25.3 min", store "peptide X elutes at iRT = 45.2"
and convert to absolute RT using a linear calibration per instrument.

**Calibration anchors (from our data):**
- Use 6-8 well-detected H3/H4 peptidoforms spanning the full RT range
- e.g., H3 K27me2me3 (~10 min), H3 unmod 3-8 (~18 min), H3 K4me1 (~21 min),
  H3 unmod 27-40 (~26 min), H3 K4ac (~35 min), H3 K122ac (~47 min)

**Advantages:**
- Instrument-agnostic once calibrated
- Can transfer RTs from ZenoTOF to Orbitrap (or any future instrument)
- Biognosys iRT concept, well-established in DIA proteomics

**Disadvantages:**
- Requires initial absolute RT measurement on each new instrument
- Assumes linear RT relationship between instruments (usually holds for RP-HPLC)
- Need at least 6 anchor peptides spanning the gradient

**Implementation:** Built into both scripts as an optional output.

### 5.3 Input Format

DeepLC expects a CSV/TSV with columns:
- `seq`: bare peptide sequence (e.g., TKQTAR)
- `modifications`: pipe-separated "position|modification" (e.g., "0|Propionyl|2|Propionyl")
- `tr`: observed retention time (for calibration peptides; leave empty for prediction)

### 5.4 Calibration Strategy

Use H3/H4 peptides with known RTs as calibration set:

| Peptide | Sequence | RT (min) | Role |
|---------|----------|----------|------|
| H3 3-8 unmod | TKQTAR | 18.34 | Low-mid RT anchor |
| H3 9-17 unmod | KSTGGKAPR | ~20 | Mid RT anchor |
| H3 27-40 unmod | KSAPATGGVKKPHR | 26.08 | Mid-high RT anchor |
| H4 4-17 unmod | GKGGKGLGKGGAKR | ~15 | Low RT anchor |
| H3 117-128 unmod | VTIMPKDIQLAR | 48.69 | High RT anchor |

After calibration, DeepLC applies a piecewise linear transformation from its
internal RT scale to the instrument-specific scale.

## 6. Empirical RT Extraction Guide

### 6.1 ms1 File Format

The .ms1 files follow the pFind/xtract centroided format:
```
H  CreationDate  ...
H  Extractor     xtract
H  ExtractorVersion  3.0.0
H  DataType      Centroided
S  000001  000001           <- scan number
I  NumberOfPeaks  426
I  RetTime  60.076000       <- RT in SECONDS
I  IonInjectionTime  0.0
300.06095 110.0             <- m/z  intensity
300.29653 2.6
...
S  000002  000002           <- next scan
```

### 6.2 XIC Extraction Algorithm

For each target peptide (known m/z at target charge state):

1. Parse all scans: collect (RT, intensity) for ions matching m/z +/- tolerance
2. Tolerance: 10 ppm for ZenoTOF (centroided data)
3. Build XIC: array of (RT_minutes, summed_intensity) across all scans
4. Smooth XIC with Savitzky-Golay filter (window=5, order=2)
5. Find peak apex: local maximum with highest intensity
6. Report: RT_apex, peak_intensity, peak_width (FWHM)

### 6.3 Quality Filters

- Minimum peak intensity: > 100 counts (instrument-dependent)
- Minimum peak width: > 0.3 min (avoid spike artifacts)
- Maximum peak width: < 5 min (avoid broad/unresolved features)
- Require detection in >= 3 of 34 samples for confidence

### 6.4 Multi-Sample Consensus

For each peptide:
1. Extract RT from all 34 samples
2. Remove outliers (> 2 SD from median)
3. Report median RT and IQR
4. Flag peptides with IQR > 1 min (unstable detection)

## 7. Multi-Instrument RT Calibration (iRT Concept)

### 7.1 iRT Definition

iRT = a * RT_absolute + b

where a, b are instrument-specific linear coefficients derived from calibration
anchors. The iRT scale is dimensionless and instrument-independent.

### 7.2 Anchor Selection

Select 8-10 H3/H4 peptides that are:
- Consistently detected across all samples
- Spanning the full gradient range (5 min to 45 min)
- Representing different hydrophobicity ranges
- Available in both ZenoTOF and Orbitrap datasets

### 7.3 Calibration Procedure

1. Measure absolute RTs for anchors on instrument A (ZenoTOF, done)
2. Assign iRT values: use the ZenoTOF scale as the reference (iRT = RT_ZenoTOF)
3. On instrument B (Orbitrap): measure anchor RTs
4. Fit linear model: RT_Orbi = a * iRT + b
5. For any peptide with known iRT: RT_Orbi_predicted = a * iRT + b

### 7.4 Expected Accuracy

Based on RT_COMPARISON.tsv analysis:
- Within same chemistry: delta < 1 min (linear calibration sufficient)
- Between different derivatization chemistries: delta up to 23.37 min
  (linear calibration insufficient, need chemistry-specific models)

## 8. Updating EpiProfile Modules

### 8.1 MATLAB Module Structure

Each H2A/H2B/H1 module contains:
```matlab
His.rt_ref = [0];  % <-- THIS is what we need to update
```

For multi-peptidoform modules:
```matlab
His.rt_ref = [0; 0; 0];  % one per mod_type entry
```

### 8.2 Update Script

After obtaining RTs (empirical or predicted), update modules with:
```matlab
% Example for HH2A_01oA1_7_14.m
His.rt_ref = [25.3];  % empirical RT from extract_empirical_rt.py
```

A MATLAB helper script `update_rt_refs.m` should:
1. Read the RT prediction table (TSV output from Python scripts)
2. For each module file, find the `His.rt_ref` line
3. Replace the zeros with predicted/empirical values
4. Preserve all other module logic unchanged

### 8.3 Validation Checklist

Before deploying updated modules:
- [ ] All rt_ref values are within [1, 43] min (gradient range)
- [ ] Unmodified forms have the earliest RT in each module (propionylation increases hydrophobicity)
- [ ] Acetylated forms elute ~1-3 min before propionylated unmod (acetyl < propionyl hydrophobicity)
- [ ] me1 forms elute slightly after unmod (methyl + propionyl > propionyl alone)
- [ ] Cross-check a few peptides manually by inspecting XICs in raw data
