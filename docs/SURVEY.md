## 1) Repository in one page (survey map)

This repo has two layers.

A) Pre-EpiProfile (format preparation)
- Goal: vendor RAW/WIFF → mzML → MS1/MS2 text files that MATLAB reads.
- Implemented here via R + shell + PowerShell (optionally via a Shiny wrapper).

B) EpiProfile core (MATLAB)
- Goal: MS1/MS2 + peptide layout panels → XIC quantification → per-run detail + cohort-level exports.

Downstream analysis (R/Python)
- Goal: parse cohort export(s), normalize, QC, stats, plots.

## 9) Troubleshooting survey (by symptom)

Choose the closest symptom.

### 9.1 “Everything is missing / outputs mostly empty”
Possible causes:
- wrong `raw_names` (basename mismatch)
- ptol too strict
- RT reference mismatch (old cache reused)
- extraction failed (MS1/MS2 incomplete/corrupted)

Actions taken:
- [ ] verified MS1/MS2 pairs exist for each raw_name
- [ ] ran 1 sample in isolation in a fresh raw_path
- [ ] removed `histone_layouts/` and reran
- [ ] loosened ptol and reran

### 9.2 “Some runs OK, one run almost blank”
Possible causes:
- conversion/extraction failed for that run
- low-signal injection / wrong sample
- basename collision

Actions taken:
- [ ] compared MS1/MS2 file sizes across runs
- [ ] checked XIC plots in `detail/` for a major peptide region
- [ ] confirmed unique basenames

### 9.3 “RT looks wrong (shifted)”
Possible causes:
- mixed LC methods in the same raw_path
- reused RT reference
- different columns/gradients

Actions taken:
- [ ] warnings: mixed LC methods split into separate raw_path
- [ ] deleted RT caches (`histone_layouts/`) and reran
